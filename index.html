Palette Cleanser

Accessibility-first color palette generator. Runs entirely in your browser.

Inputs

Required. Hex with or without #.

How this works

Each palette is seeded from your primary color using a different harmony strategy (analogous, complementary, triadic, split-complementary, monochromatic) computed in OKLCH. Neutrals are derived to harmonize with the brand hue; semantic colors (success / warning / error) start from canonical hues and are lightness-adjusted to pass WCAG 2.1 AA contrast against the background.

Color blindness simulations use the Machado et al. (2009) matrices for deuteranopia, protanopia, and tritanopia, applied in linear RGB. Achromatopsia uses BT.709 luminance.

Colors are flagged if two roles become perceptually indistinguishable under any simulation (ΔE in OKLab below a distinguishability threshold) or if any required text/background pair fails AA. Anchored input colors are never silently altered — only flagged.
